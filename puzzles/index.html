Math puzzles you can try yourself

Each Brain vs Math video asks a question with a surprising answer. Here you can work it out with your own hands: count the pieces one at a time, or unfold the shape and measure. Every page has the short video too.

The spider and the fly
The obvious path is 42. Unfold the room and the shortest is 40, across five walls. How many squares on a chessboard?
Not 64. Count every size up to the whole board: 204. How many triangles?
A triangle cut into 16 small ones holds 27, if you count the ones pointing down.

For teachers

Every puzzle page has an embed code at the bottom, so you can put the interactive part on a class page or a learning platform. It is free to use for teaching, with the link back kept.
