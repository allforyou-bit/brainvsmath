Frequently asked questions

Is everything on this page really free?

Yes — every worksheet, tool and the 60-sheet multiplication pack is free for classroom, tutoring and home use. No signup, no watermark, no limits.

Where should my class start after the summer?

One grade level below where they finished last year, for about two weeks. Summer fade is normal; the ready-to-print sets above are already pitched as review so week one builds confidence instead of frustration.

Can I run different groups on different worksheets?

Yes. Every worksheet link carries a code (seed) that recreates the identical sheet. Make one set per group, bookmark the links, and reprint any of them all term.

Do worksheets come with answer keys?

Yes — the key prints on its own final page, so you hand out the problems and keep the answers.
